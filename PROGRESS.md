# PROGRESS — Samsung Galaxy Note 10 Lite (SM-N770F, `r7`/`r7n`) — Droidian / Halium Track

> **Track ini = paralel & komplementer** dengan `../r7-mainline/PROGRESS.md` (track mainline+pmOS via uniLoader).
> **Tujuan track ini:** boot **Droidian** (Debian/Phosh) di r7 via **Halium** = kernel downstream 4.9 + blob vendor Android, BUKAN mainline.
> **Device:** SM-N770F · SoC **Exynos 9810** (10 nm) · codename `r7`/`r7n` · firmware **Android 13** (`N770FXXS9HXA3`, region XID).

## MENGAPA TRACK INI (feasibility — riset sesi 7)

Observasi pembeda: **mayoritas HW r7 tak punya mainline driver** (lihat tabel HW di `r7-mainline/docs/samsung-r7-device-page.md`). Itu persis masalah yang Halium sidestep — dengan **memakai ulang kernel+blob vendor**, bukan menulis driver. Keputusan strategis:

| | **Mainline** (track `r7-mainline`) | **Halium/Droidian** (track ini) |
|---|---|---|
| Pakai ulang | upstream 9810 dtsi (pinctrl/chipid/gic/timer saja) | **kernel downstream 4.9 — menggerakkan SEMUA HW r7** + blob vendor |
| Display/touch/modem/wifi/BT/audio/camera/NFC | ❌ harus tulis driver (kebanyakan tak ada) | ✅ via blob vendor + kernel downstream |
| **Tembok** | **CMU driver belum di-port** → tak ada peripheral ber-clock yang probe (UART/UFS/USB/panel/WiFi). Port CMU = bulanan, hanya untuk *buka kunci* | Tak ada tembok — kernel downstream sudah punya semua clock+driver |
| Hasil realistis | framebuffer console + mungkin UART/USB = dev toy | **ponsel Debian/Phosh** (calls/SMS/data, wifi, BT, audio, kamera) |
| Waktu ke "usable" | bulan–tahun, kemungkinan tak pernah paritas | ~1–2 minggu kerja fokus |
| Feasibilitas di laptop 14 GB RAM | ✅ build kernel ringan | ✅ **tak perlu build Android penuh** — pakai blob vendor on-device + flash rootfs prebuilt. Lebih ringan daripada ROM LineageOS penuh (butuh 64 GB RAM) |
| Biaya | kernel modern, bersih, upstreamable | terkunci di 4.9 (keamanan), ketergantungan blob Android, libhybris rapuh |

### Bukti bahwa path ini viable (bukan teori)

- **Droidian AKTIF.** Droidian 101 (patchlevel 2025-09-06 & 2025-11-30), **nightly build serendah 6 Juli 2026** (saat riset sesi 7), dev branch 102 terbuka. Berbasis Debian sid + GNOME 48 + Phosh 0.49.0. — [droidian-images/droidian releases](https://github.com/droidian-images/droidian/releases) · [droidian.org](https://droidian.org/)
- **Mendukung Halium 13 / API 33 (Android 13)** — **cocok persis firmware r7** kita (`N770FXXS9HXA3` = Android 13). Alignment versi blob adalah gotcha #1 Halium; kita sudah punya vendor partition yang cocok. — [Droidian 101 release notes](https://github.com/droidian-images/droidian/releases/tag/droidian%2F101.20250906)
- **Famili Exynos 9810 SUDAH punya port Droidian** → adaptasi level-SoC terbukti:
  - [droidian-devices/linux-android-samsung-crownlte](https://github.com/droidian-devices/linux-android-samsung-crownlte) — kernel Droidian Note 9 (`droidian` branch, Des 2023) = **template kita**.
  - [Sexynos/droidian-images-crownlte](https://github.com/Sexynos/droidian-images-crownlte) & [droidian-images-starlte](https://github.com/Sexynos/droidian-images-starlte) — image fastbootable Note 9 / S9.
  - [droidian-kernel-samsung-exynos9810](https://github.com/Sexynos/droidian-kernel-samsung-exynos9810) (archived).
- **r7 eligible:** launch Android 10 → "Android 9+" ✓ · GSI-capable (Samsung) ✓ → porting guide bilang **"hanya kernel changes typically needed"** + `DEVICE_VBMETA_IS_SAMSUNG=1`. — [porting guide](https://github.com/droidian/porting-guide/blob/master/kernel-compilation.md)
- **Kita sudah pegang SEMUA aset yang dibutuhkan** (lihat TASK 0 — diwarisi dari `r7-mainline`): firmware stock Android 13, PIT 39-partisi, golden values (kernel base/pagesize/initrd/FB/memory), downstream DTB 9373 baris, toolchain cross-compile Fedora.

### Rekomendasi (disetujui user sesi 7)

1. **Kejar Droidian/Halium untuk ponsel Linux yang bisa dipakai SEKARANG.** Realita "HW tak punya mainline driver" = alasan Halium ada. Precedent crownlte + firmware Android 13 + defconfig downstream r7 = path friction terendah.
2. **Tetap pertahankan mainline sebagai track proper jangka panjang.** uniLoader + mainline = jalur bersih/upstreamable, tapi scope sebagai riset milestone-driven (M1→UART→USB→UFS), BUKAN jalur ke daily-driver. CMU wall bikin full mainline = multi-tahun, kemungkinan tak paritas untuk satu orang.
3. **Bagi aset repo.** Ekstraksi firmware, PIT/layout partisi, `r7-mainline/docs/unbrick.md`, Heimdall flashing, dan **tabel HW** = reusable untuk Droidian (tabel bahkan dokumentasi *apa yang kernel downstream sudah kendarai* = apa yang akan jalan di Halium). Kerja uniLoader sendiri **orthogonal** (Halium pakai stock boot path, BUKAN uniLoader).

### Caveat jujur (bukan dealbreaker — catat sebagai risk)

- **Repositori device Exynos-9810 Droidian archived (~2023).** Maintained successor `droidian-devices/linux-android-samsung-crownlte` juga late-2023. Artinya: kita menghidupkan ulang adaptasi device 2023-era ke core Droidian 2026. Kerja nyata tapi terbatas (mayoritas: kernel config + fstab/init + Halium initramfs). SoC + layer Halium 13 didukung core; bit device-specific = adaptasi.
- **Kernel wajib rebuild dengan config Halium:** binder, ashmem, SELinux permissive (atau bypass defex/Knox), `DEVICE_VBMETA_IS_SAMSUNG=1`. Stock 4.9.191 dari firmware kita enforcing SELinux + Samsung defex → blok libhybris. Toolchain cross-compile sudah siap.
- **Kernel↔vendor alignment:** kita pegang firmware **Android 13** → pakai kernel **era-Android-13** (4.9.191 stock, atau source downstream era sama) + Halium 13 (API 33). Defconfig `duhansysl/exynos9810-kernel` branch `N770F` = 4.9.337 / OneUI 7 (Android 15) — **mungkin lebih baru** dari vendor kita. Opsi: (a) pakai source kernel era Android 13 yang cocok vendor; (b) update firmware device ke Android 13/14/15 yang cocok kernel duhansysl. Lihat TASK 1.3.
- **Fitur broken pada port crownlte Droidian** (asumsi serupa di r7): GPS ❌, fingerprint ❌, offline charging ❌, dual-SIM ❌ (hanya satu SIM). ≈90%, bukan 100%. Tapi = *ponsel*, bukan framebuffer. → Daftar di "Issue tracker" bawah.

Kamu adalah agen yang mengeksekusi runbook ini. Aturan main (sama dengan `r7-mainline`):

1. **Tag langkah:**
   - `[CC]` = kerjakan sendiri (tulis file/script, diff terhadap device referensi, build di host, download aset prebuilt).
   - `[HW]` = tidak bisa kamu lakukan. Cetak perintah persis + checklist, minta user jalankan di hardware, **tunggu output user** sebelum lanjut. **Jangan mengarang hasil hardware.**
   - `[GATE]` = acceptance check. **Dilarang lanjut** ke task berikutnya sebelum gate lolos.

2. **Prinsip #1 — diff, bukan tulis dari nol.** Exynos 9810 di r7 = identik dengan Note 9 (`crownlte`). **Baseline Droidian = `droidian-devices/linux-android-samsung-crownlte`** (kernel + device config). Ambil crownlte, ubah HANYA yang beda di r7: panel 1080×2400 (crownlte 1440×2560 QHD), layout memori 8GB (crownlte 6GB), key map (r7 tanpa wink/Bixby; pin dari DTBO `dtbo_idx=5`), MUIC/PMIC/sensor (BOM dari DTBO r7). SoC/clock/GIC/timer/USB/UFS/modem-CP → salin apa adanya.

3. **Awal tiap sesi:** `git status` (di repo `r7-mainline` — track ini berbagi repo), baca `PROGRESS.md` ini + `../r7-mainline/PROGRESS.md`, laporkan task aktif + gate berikutnya. Jangan ulang kerja yang sudah lolos gate.

4. **Jangan pernah** commit blob firmware/boot image / rootfs Droidian (gitignore). Jangan skip prasyarat unbrick — walau track ini flash boot+userdata (BL tak pernah ditulis, unbrick = re-flash stock boot).

5. **Golden values** (kernel base, pagesize, initrd addr, FB base, memory layout) — **AMBIL DARI `../r7-mainline/PROGRESS.md` tabel golden-values** (sudah tervalidasi sesi 5 dari device rooted). Halium boot.img pakai nilai yang SAMA dengan stock Android boot v2 (base `0x10000000`, pagesize `2048`, dt-table Samsung). Jangan tebak.

6. **Diskresi teknis track ini:**
   - boot.img Halium = **kernel downstream 4.9 + initramfs Halium + DTB downstream r7** (Samsung dt-table). **BUKAN** uniLoader, **BUKAN** kernel/Image mainline. DTB = downstream r7 (dari `r7-mainline/firmware/images/r7-downstream.dtb`), BUKAN `exynos9810-samsung-r7.dtb` mainline.
   - Flash path = **Heimdall** (Samsung Download Mode), BUKAN fastboot. Aset wrap (`r7-mainline/boot/`) reusable: mkbootimg, base, pagesize, dt-table, `SEANDROIDENFORCE`.
